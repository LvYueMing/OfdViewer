# OFD Viewer 测试文档

## 测试项目概述

OfdViewer.Test 是 OFD Viewer 项目的测试项目，用于验证 OFD 文档处理库的功能正确性和稳定性。该项目使用 .NET 8.0 框架，包含了对 OFD 文档处理库各个核心组件的测试用例。

## 测试覆盖范围

### 核心组件测试

| 测试文件 | 测试对象 | 测试内容 |
|---------|---------|---------|
| OfdArchiveTests.cs | OFDArchive 类 | OFD 归档的读取、写入、文件管理等功能 |
| OFDDocTests.cs | OFDDocument 类 | OFD 文档的基本结构和属性测试 |
| OFDDocumentTests.cs | OFDDocument 类 | OFD 文档的完整处理流程测试 |
| OFDWriterTests.cs | OFDWriter 类 | OFD 文档的写入和生成功能测试 |
| RegionAreaTests.cs | RegionArea 类 | 区域面积计算功能测试 |
| RootOFDTests.cs | RootOFD 类 | OFD 全局元数据测试 |
| ST_ArrayTests.cs | ST_Array 类 | 数组类型测试 |
| ST_LocTests.cs | ST_Loc 类 | 位置类型测试 |

### 测试类型

1. **单元测试**：测试单个类或方法的功能正确性
2. **集成测试**：测试多个组件之间的协作关系
3. **功能测试**：测试完整的 OFD 文档处理流程
4. **边界测试**：测试极端情况下的处理能力
5. **异常测试**：测试异常情况的处理机制

## 如何运行测试

### 在 Visual Studio 中运行测试

1. 打开解决方案文件 `OfdViewer.sln`
2. 点击顶部菜单 "测试" -> "测试资源管理器"
3. 在测试资源管理器中，选择要运行的测试项目或测试用例
4. 点击 "运行所选测试" 按钮
5. 查看测试结果和覆盖率报告

### 使用命令行运行测试

```bash
dotnet test
```

#### 运行指定测试项目

```bash
dotnet test OfdViewer.Test/OfdViewer.Tests.csproj
```

#### 运行指定测试类

```bash
dotnet test --filter FullyQualifiedName~OfdViewer.Test.OFDArchiveTests
```

#### 运行指定测试方法

```bash
dotnet test --filter FullyQualifiedName~OfdViewer.Test.OFDArchiveTests.TestOpenFromFile
```

## 测试结果分析

### 测试状态

- ✅ 已通过：测试用例执行成功，功能正常
- ❌ 已失败：测试用例执行失败，需要修复
- ⚠️  跳过：测试用例被跳过，通常是因为前置条件不满足

### 测试覆盖率

测试覆盖率是衡量测试质量的重要指标，包括：

- **语句覆盖率**：测试执行的代码语句占总语句的比例
- **分支覆盖率**：测试执行的代码分支占总分支的比例
- **路径覆盖率**：测试执行的代码路径占总路径的比例

在 Visual Studio 中，可以通过 "测试" -> "分析代码覆盖率" 查看详细的覆盖率报告。

## 测试用例编写规范

1. **命名规范**：测试类和测试方法的命名应清晰反映测试对象和测试内容
2. **单一职责**：每个测试用例应只测试一个功能点
3. **前置条件**：明确测试用例的前置条件
4. **断言明确**：使用明确的断言语句验证测试结果
5. **异常处理**：正确测试异常情况
6. **清理资源**：测试完成后正确清理资源
7. **注释清晰**：为复杂的测试用例添加必要的注释

## 常见问题

### 测试失败的常见原因

1. **环境问题**：测试环境与开发环境不一致
2. **依赖问题**：依赖的组件版本不兼容
3. **测试数据问题**：测试数据损坏或格式不正确
4. **代码变更**：代码变更导致测试用例失效
5. **并发问题**：多线程环境下的测试竞争

### 如何调试测试用例

1. 在测试方法上设置断点
2. 右键点击测试方法，选择 "调试所选测试"
3. 使用 Visual Studio 的调试工具查看变量值和执行流程
